# NBS 雲端保單體檢

富邦人壽保險顧問專用保單體檢系統

## 系統架構
- 前端：GitHub Pages（純 HTML/CSS/JS）
- 後端：Google Apps Script
- 資料庫：業務員個人 Google Drive
- 授權名單：Google Sheets

## 部署說明
1. 將此 repo 開啟 GitHub Pages（Settings → Pages → Deploy from main branch）
2. 取得 Google OAuth Client ID 填入 index.html
3. 業務員開啟 https://ingbaker-bot.github.io/nbs-insurance/ 即可使用
